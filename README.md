# ERP Core (Yokiverse)

An independent, bespoke modern ERP and double-entry accounting engine built from the ground up.

## 🛠️ Tech Stack
- **Backend**: Python 3.12, Django, Django REST Framework (DRF)
- **Frontend**: React, Vite, TypeScript, TanStack Table, Lucide Icons
- **Database**: MariaDB / MySQL 8.0 (InnoDB engine, ACID transactions)

## 📂 Project Structure
```
erp_core/
├── backend/          # Django REST API & Accounting service engine
│   ├── accounting/   # Chart of Accounts, General Ledger, Journals
│   └── server/       # Django project configuration
└── frontend/         # React + Vite + TypeScript application
    └── src/          # UI components, data grids & views
```
